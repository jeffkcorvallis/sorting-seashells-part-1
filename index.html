Shell sorter: build a phylogenetic tree

You have 20 shells, each shown from two sides. Your job is to work out which ones are close relatives and draw the family tree that shows it.

  1. Look closely at both sides of each shell. Note shape, spire, opening, texture and pattern.
  2. Select two or more shells that share a trait you think is inherited from a common ancestor.
  3. Type the shared trait, then choose Group. Repeat, joining groups to groups, until everything is in one tree.
  4. Choose Check my tree to compare it with a reference tree and think about where you might be fooled.

Questions to discuss
  1. Which traits did you use first? Are they ones every shell has, or ones only some have?
  2. Did any two shells look alike but end up far apart in the reference tree? Convergent evolution can produce similar shapes in unrelated lineages.
  3. Which single shell was hardest to place, and what extra evidence (DNA, anatomy, fossils) would help?
  4. Why is the scallop a useful outgroup for the snails?
Teacher note

The reference tree is a simplified one based on the shells’ broad families: scallop (bivalve outgroup); nerites; cowries; cone snails; and two predatory relatives (shells 3 and 20, spiny and spindle-shaped). Shell 8 is treated as a triton-type snail. These identifications come from photos, so please confirm them against your specimen key before grading. Any grouping that students can justify with a shared, inherited trait is worth discussing even when it differs from the reference.
